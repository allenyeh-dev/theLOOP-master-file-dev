# Template A — SOP Update

For any standard operating procedure (operations, HR, bar, FOH, kitchen, security, cashiering, reception, compliance, etc.).

## 1. Identification

| Field | English | 中文 (Chinese) |
| --- | --- | --- |
| SOP number (existing) | e.g. KOR-BAR-005 — leave blank if it is a new item | Same as English; leave blank if new |
| Venue / brand | CLV Boon / KOR / SPC Kitchen / other | 分店 / 品牌 |
| Department / category | e.g. Bar Operations | 部門 / 分類 |
| Audience (role) | e.g. Bartender, Bar Back | 適用對象 |

## 2. Content

| Field | English | 中文 (Chinese) |
| --- | --- | --- |
| Title | A short, clear title | 標題 |
| Purpose | One or two sentences: why this SOP exists / what it covers | 目的說明 |
| Key standards (bullets) | List each standard, e.g.:<br>• Standard 1<br>• Standard 2<br>• Standard 3 | List each standard in the same order as English:<br>• 準則一<br>• 準則二<br>• 準則三 |
| Steps (numbered) | 1. First step<br>2. Second step<br>3. Third step<br>(the count must match the Chinese column) | 1. 第一步<br>2. 第二步<br>3. 第三步<br>(the step count must match English) |

## 3. Submission notes

Anything unclear, any information you are unsure about, or any part marked "NEEDS CONFIRMATION" above — explain it here.

## Example — correctly filled in (SOP)

| Field | English | 中文 (Chinese) |
| --- | --- | --- |
| SOP number | KOR-BAR-013 (new) | Same as English |
| Title | Restocking Garnish Station | 補充裝飾物工作站 |
| Purpose | To ensure the garnish station never runs short during service. | 確保營業期間裝飾物工作站不缺料。 |
| Key standards | • Check garnish levels every hour<br>• Restock before dropping below 20%<br>• Log restocks in the shift handoff | • 每小時檢查裝飾物存量<br>• 低於20%前即補貨<br>• 於交班紀錄中記錄補貨情形 |
| Steps | 1. Check station at the top of each hour<br>2. Restock any item below 20%<br>3. Note restock in handoff log | 1. 每小時整點檢查工作站<br>2. 補充低於20%之品項<br>3. 於交班紀錄中註記補貨情形 |
