# Template B — Recipe Update

For any cocktail, bar or kitchen recipe.

## 1. Identification

| Field | English | 中文 (Chinese) |
| --- | --- | --- |
| Recipe number (existing) | e.g. KOR-RCP-045 — leave blank if it is a new item | Same as English; leave blank if new |
| Venue / brand | CLV Boon / KOR | 分店 / 品牌 |
| Menu category | e.g. Signature Cocktails, Seasonal, Classic Cocktails, Dinner | 菜單分類 |
| Audience (role) | e.g. Bartender, Bar Back | 適用對象 |

## 2. Content

| Field | English | 中文 (Chinese) |
| --- | --- | --- |
| Item name | Name as shown on the menu | 菜單品項名稱 |
| Ingredients (strict format: quantity \| unit \| name) | 45 \| ml \| Gin<br>20 \| ml \| Fresh Lime Juice<br>15 \| ml \| Simple Syrup<br>(each ingredient has exactly 2 "\|" symbols — the app uses them to split quantity / unit / name. Do not write "45ml Gin" as one block.) | 45 \| ml \| 琴酒<br>20 \| ml \| 新鮮萊姆汁<br>15 \| ml \| 糖漿 |

| Notes / source | Any house-made components, substitutions, or sourcing details worth noting | 自製配料、替代方案或採購相關備註 |

## 3. Submission notes

Anything unclear, any information you are unsure about, or any part marked "NEEDS CONFIRMATION" above — explain it here.

## Why this matters

The final app only works when the Chinese layer of every record is clean and complete — this is a hard technical requirement, not a style preference. If an update leaves out one language, the Chinese steps are in a different order than the English, or a field is unclear, the staff-facing bilingual switch breaks or the update has to be redone. Filling this template completely the first time is the fastest way to go live.
